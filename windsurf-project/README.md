# 💰 Pencatatan Keuangan

Aplikasi web pencatatan keuangan sederhana dengan React, Vite, dan TailwindCSS.

## Fitur

- ✅ Catat pemasukan dan pengeluaran
- ✅ Lihat ringkasan saldo, total pemasukan, dan pengeluaran
- ✅ Kategorisasi transaksi
- ✅ Edit dan hapus transaksi
- ✅ Data tersimpan di localStorage (tidak hilang saat refresh)
- ✅ Desain modern dan responsif

## Cara Menjalankan

1. Install dependencies:
```bash
npm install
```

2. Jalankan development server:
```bash
npm run dev
```

3. Buka browser di URL yang ditampilkan

## Teknologi

- React 18
- Vite
- TailwindCSS
- Lucide Icons
- date-fns
